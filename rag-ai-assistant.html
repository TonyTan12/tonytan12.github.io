RAG AI Assistant

Document ingestion and hybrid retrieval with source citations.

Source on GitHub

Purpose

I built a document question-answering system to explore how retrieval and source metadata support traceable answers. The API retrieves relevant passages before asking an OpenAI model to generate a response.

Document ingestion

The Python pipeline reads PDF, Word, and text files. Overlapping chunks preserve context across boundaries. Each chunk receives an embedding and source metadata before storage in ChromaDB.

Retrieval and answers

Vector search retrieves related passages. BM25 adds keyword matches for exact terms. The retrieval layer combines scores and assembles context for the model. Responses include source citations for review.

API and diagnostics

FastAPI exposes a query endpoint and health checks. Pydantic models define request and response fields. Debug endpoints help inspect embedding dimensions, database state, and retrieved passages.

Stack

Python, FastAPI, Pydantic, OpenAI API, ChromaDB, BM25, and Git.
