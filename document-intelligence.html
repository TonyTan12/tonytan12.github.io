Document Intelligence Pipeline

Extract structured fields from PDFs and images.

Source on GitHub

Purpose

I built a pipeline to turn document content into structured JSON for downstream processing. The workflow combines OCR with document classification and field extraction.

Processing flow

PDF pages and images pass through preprocessing before text extraction. Tesseract performs OCR. An EasyOCR fallback handles low-confidence results. OpenAI classifies the document and extracts fields from the text.

Structured output

Pydantic models define document, field, and response formats. Results include extracted values and confidence scores. These scores help identify records for review.

API

FastAPI exposes document upload, batch-processing, and result-retrieval endpoints. Processing status and results are available through the API.

Stack

Python, FastAPI, Pydantic, Tesseract, EasyOCR, Pillow, OpenAI API, and JSON.
