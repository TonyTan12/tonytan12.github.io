Timeline Atlas

Interactive maps and analytics for Google Timeline data.

Purpose

I built Timeline Atlas to explore location history through maps and time-based analytics. The local dataset contains 5,488 visits across 1,845 places. This page describes the implementation and aggregate counts.

Map and analysis

The JavaScript interface uses Leaflet to display places and travel paths. Date and place-type filters narrow the view. Rankings show visit frequency, recent visits, and estimated dwell time. Filtered results export to CSV.

Route rendering

Route data loads when the travel-path layer is enabled. Canvas rendering displays map points and routes. Date and viewport checks limit the paths drawn. Local storage retains place aliases.

Timeline Galaxy

A second Canvas view displays places by direction, distance, and visit frequency or dwell time. A month slider and playback controls show changes over time.

Stack

JavaScript, HTML/CSS, Leaflet, Canvas, JSON, browser local storage, and CSV export. The source and location dataset are kept locally.
